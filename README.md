# RectificaPro — Calculadoras de rectificado

Web estática en español para cálculos geométricos orientativos relacionados con rectificado de cilindros.

## Herramientas incluidas
- Diámetro final objetivo y sobremedida diametral/radial.
- Cilindrada por cilindro y total.
- Velocidad de giro (rpm) a partir de velocidad de corte y diámetro.
- Volumen geométrico de material retirado.

## Publicar con GitHub Pages
1. En el repositorio, abre **Settings → Pages**.
2. En **Build and deployment**, selecciona **Deploy from a branch**.
3. Elige la rama `main` y la carpeta `/(root)`; guarda.
4. GitHub mostrará la URL pública cuando termine el despliegue.

La web no necesita compilación, dependencias ni servidor: se sirve directamente desde `index.html`.

## Aviso técnico
Los cálculos son aproximaciones geométricas. No sustituyen tolerancias, holguras, sobremedidas permitidas ni procedimientos del fabricante de la pieza, motor, máquina o abrasivo.
